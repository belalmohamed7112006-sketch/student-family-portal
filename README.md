# بوابة أسرة طلاب من أجل مصر — نسخة تأسيسية

## محتويات الملفات
- `index.html`: واجهة عربية متجاوبة لتسجيل الدخول والتسجيل وملف العضو ولوحة مراجعة المدير.
- `config.js`: إعدادات اتصال Supabase.

## قبل النشر
1. افتح `config.js`.
2. ضع Project URL و anon/public key من Supabase > Project Settings > API.
3. لا تضع `service_role` key أو كلمة مرور قاعدة البيانات في هذا الملف.
4. تأكد من وجود سياسات RLS تسمح للمدير بقراءة وتحديث طلبات الأعضاء والأنشطة، وتسمح للعضو المعتمد بإرسال نشاط.

## رفع الملفات
ارفع `index.html` و`config.js` إلى جذر مستودع GitHub، وليس ملف ZIP نفسه.
ثم في Vercel اختر Add New > Project واستورد المستودع.

## ملاحظات
- التسجيل يستخدم البريد الإلكتروني وكلمة المرور عبر Supabase Auth.
- حسابات الأعضاء تحتاج موافقة المدير.
- كلمة المرور لا تُخزن في جدول profiles ولا يمكن للمدير رؤيتها.
- لا تستخدم رقمًا قوميًا حقيقيًا في الاختبارات الأولية.
- هذه نسخة تأسيسية؛ يلزم اختبار سياسات قاعدة البيانات وإعداد تأكيد البريد وروابط إعادة التعيين قبل إطلاقها للعامة.
