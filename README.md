# بوابة أسرة طلاب من أجل مصر — إصدار التصميم الأول

## محتويات الحزمة
- `index.html`: واجهة الموقع الجديدة مع صفحات التعريف، اللجان، تسجيل الدخول، إنشاء الحساب ولوحات العضو والإدارة.
- `config.js`: إعدادات اتصال Supabase الحالية للمشروع.
- `README.md`: هذا الملف.

## طريقة الاستبدال
1. فك ضغط الملف.
2. ارفع الملفات الثلاثة إلى جذر مستودع GitHub `student-family-portal` واستبدل النسخ القديمة.
3. انتظر انتهاء النشر التلقائي على Vercel ثم افتح رابط الموقع.

## ملاحظات
- تم الحفاظ على معرفات عناصر النماذج ومنطق Supabase الحالي (تسجيل الدخول، إنشاء الحساب، استعادة كلمة المرور، المشاركات، ولوحة المدير) أثناء إعادة تصميم الواجهة.
- هذا إصدار التصميم الأول: المشهد الكروي في الواجهة عنصر بصري ثابت مؤقتًا؛ تحريك الكاميرا من الأرض إلى مصر ثم الإسماعيلية والجامعة سيكون مرحلة الأنيميشن التالية بعد اعتماد الشكل.
- لا تضع `service_role` أو أي مفتاح سري داخل `config.js`. المفتاح الموجود هنا هو المفتاح العام Publishable للمشروع.
